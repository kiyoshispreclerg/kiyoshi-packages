kiyoshi-packages

Repositório apt com os programas do Kiyoshi e o XLibre, para Ubuntu 22.04/24.04/26.04, Linux Mint 21/22 e Debian 12/13 (e Devuan 5/6, LMDE 7). Arquitetura: amd64.

Jeito fácil: baixe kiyoshi-packages-repo_all.deb e instale (duplo clique no gerenciador de pacotes, ou sudo apt install ./kiyoshi-packages-repo_all.deb). Ele instala a chave e a fonte apt do seu sistema; depois é só sudo apt update. Para escolher o canal do XLibre (nenhum, stable ou beta): sudo dpkg-reconfigure kiyoshi-packages-repo. Remover o pacote remove a fonte e a chave.

Ou manualmente:

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/kiyoshi-packages.gpg URL/kiyoshi-packages.gpg
echo "deb [signed-by=/etc/apt/keyrings/kiyoshi-packages.gpg] URL SUITE main beta" |
  sudo tee /etc/apt/sources.list.d/kiyoshi-packages.list
sudo apt update

Componentes: main (programas), mais um entre stable (XLibre 25.1) e beta (XLibre 25.2); ambos também oferecem o xserver-xis-core.

SUITE: jammy (Ubuntu 22.04, Linux Mint 21), noble (Ubuntu 24.04, Linux Mint 22), resolute (Ubuntu 26.04), bookworm (Debian 12, Devuan 5), trixie (Debian 13, Devuan 6, LMDE 7).
