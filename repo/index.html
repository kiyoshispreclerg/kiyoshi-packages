kiyoshi-packages

Repositório apt para Ubuntu 22.04/24.04 e Debian 12/13 (e Devuan 5/6).

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/kiyoshi-packages.gpg URL/kiyoshi-packages.gpg
echo "deb [signed-by=/etc/apt/keyrings/kiyoshi-packages.gpg] URL SUITE main" |
  sudo tee /etc/apt/sources.list.d/kiyoshi-packages.list
sudo apt update

SUITE: jammy (Ubuntu 22.04), noble (24.04), bookworm (Debian 12, Devuan 5), trixie (Debian 13, Devuan 6).
