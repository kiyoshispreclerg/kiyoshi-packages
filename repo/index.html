kiyoshi-packages

An apt repository with Kiyoshi's programs and XLibre, for Ubuntu 22.04/24.04/26.04, Linux Mint 21/22 and Debian 12/13 (and Devuan 5/6, LMDE 7). Architecture: amd64.

Easy way: download kiyoshi-packages-repo_all.deb and install it (double-click in the package manager, or sudo apt install ./kiyoshi-packages-repo_all.deb). It installs the key and the apt source for your system; then just sudo apt update. To choose the XLibre channel (none, stable or beta): sudo dpkg-reconfigure kiyoshi-packages-repo. Removing the package removes the source and the key.

Or manually:

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/kiyoshi-packages.gpg URL/kiyoshi-packages.gpg
echo "deb [signed-by=/etc/apt/keyrings/kiyoshi-packages.gpg] URL SUITE main beta" |
  sudo tee /etc/apt/sources.list.d/kiyoshi-packages.list
sudo apt update

Components: main (programs), plus one of stable (XLibre 25.1) or beta (XLibre 25.2); both also offer xserver-xis-core.

SUITE: jammy (Ubuntu 22.04, Linux Mint 21), noble (Ubuntu 24.04, Linux Mint 22), resolute (Ubuntu 26.04), bookworm (Debian 12, Devuan 5), trixie (Debian 13, Devuan 6, LMDE 7).
